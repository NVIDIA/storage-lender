# Maintainers

Maintainers are responsible for technical direction, review, issue triage, security coordination,
release evidence, and repository stewardship. Reviewers provide domain-specific review but do not
merge without maintainer approval.

Repository roles are represented by these NVIDIA GitHub teams:

- `@NVIDIA/storage-lender-maintainers`: maintainers and path owners. This team supplies required
  CODEOWNERS review.
- `@NVIDIA/storage-lender-team`: contributors and domain reviewers. Membership does not grant
  maintainer or merge authority.

Current path ownership is defined in [`.github/CODEOWNERS`](.github/CODEOWNERS).

Security reports must follow the [repository security policy](SECURITY.md). Maintainers carefully
consider feedback and contributions and retain final responsibility for accepting changes and
releases.
