# Support

## Support level

Storage Lender is **Experimental**. It is intended for evaluation on dedicated, explicitly
provisioned systems and is not supported for production or business-critical workloads.

## Getting help

Use [GitHub Issues](https://github.com/NVIDIA/storage-lender/issues) for non-security bug reports,
documentation problems, and feature requests. Include the Storage Lender commit or version, host and
kernel details, SPDK version, hardware identity, configuration with sensitive values removed,
reproduction steps, and relevant logs.

There is no response-time, resolution-time, compatibility, or long-term-support guarantee. Patches,
workarounds, and release timing remain subject to maintainer capacity and project priorities.

Do not report vulnerabilities publicly. Use the private NVIDIA PSIRT channels described in the
repository security policy.
